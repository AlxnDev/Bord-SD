# 📝 Bord-SD
> **The minimalist, high-speed alternative to Word for seamless text editing.**

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?style=for-the-badge&logo=python&logoColor=white)
![PyQt6](https://img.shields.io/badge/PyQt6-GUI-41CD52?style=for-the-badge&logo=qt&logoColor=white)
![Build](https://img.shields.io/badge/Windows-Executable-blue?style=for-the-badge&logo=windows&logoColor=white)

**Bord** is a lightweight text processor designed for users who need the core functionality of Microsoft Word without the bloat. Built with Python and PyQt6, it focuses on what matters most: **writing, editing, and saving simple text fast.**

---

## ✨ Why choose Bord?

* 📄 **Word-Inspired, Performance-Driven:** Get the editing power you need without waiting for a heavy office suite to load.
* 🚀 **Instant Launch:** Optimized for speed—open your files and start typing in milliseconds.
* 💾 **Smart Saving:** Effortlessly manage and save your documents with a clean, intuitive interface.
* 📦 **Fully Portable:** No installation required. Carry the `.exe` on a USB drive and work on any Windows PC.

---

## 🚀 Getting Started

### 1. Download the Executable (.exe)
Visit the **[Releases](https://github.com/AlxnDev/Bord-SD/releases)** section and download `bord_pro.exe`. Just run it and start writing!

### 2. For Developers (Source Code)
If you want to run the project locally or contribute:
```bash
# Clone the repository
git clone [https://github.com/AlxnDev/Bord-SD.git](https://github.com/AlxnDev/Bord-SD.git)

# Navigate to the folder
cd Bord-SD

# Install dependencies
pip install PyQt6

# Run the application
python bord_pro.py
