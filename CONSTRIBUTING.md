# 🤝 Contributing to Bord-SD

First off, thank you for considering contributing to **Bord-SD**! It's people like you who make this a better tool for everyone.

Below is a set of guidelines to help you contribute effectively.

---

## 🚀 How Can I Contribute?

### Reporting Bugs
* Check the **Issues** tab to see if the bug has already been reported.
* If not, open a new issue. Include:
    * A clear title.
    * Steps to reproduce the bug.
    * Your Python version and OS (Windows/Linux).

### Suggesting Enhancements
We are always looking for ways to make **Bord** faster and simpler!
* Open an issue with the tag `enhancement`.
* Explain why this feature would be useful for a minimalist text editor.

### Pull Requests (Code Changes)
1. **Fork** the repository.
2. Create a new branch: `git checkout -b feature/your-feature-name`.
3. **Make your changes.**
4. Ensure your code follows the project style (PEP 8 for Python).
5. **Commit** your changes: `git commit -m 'Add some feature'`.
6. **Push** to the branch: `git push origin feature/your-feature-name`.
7. Open a **Pull Request**.

---

## 🛠️ Development Setup

To set up your environment:
1. Clone your fork.
2. Install dependencies: `pip install PyQt6 pytest`.
3. Run the application: `python bord_pro.py`.
